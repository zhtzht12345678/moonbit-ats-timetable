# 8 月黑客松申报摘要

## 项目名称

MoonBit 列车自动监控（ATS）运行图调度与实时冲突检测器。

## 项目性质

原创 MoonBit 工程，未移植第三方 ATS 实现。核心算法、数据模型、解析器、监控状态机、调度建议器和渲染输出全部由本仓库的 MoonBit 源码实现。项目只依赖 MoonBit 官方核心 JSON 包。

## 应用场景

面向轨道交通 OCC 的离线运行图校验、演练、实时状态接入和人工调度辅助。它不直接控制信号设备，输出的是可解释的冲突告警、影响范围和建议动作，适合作为上层调度系统的规则引擎或仿真前置校验器。

## 本阶段范围

1. 运行图标准模型：线路、车站、区间、车次、停站和进路资源。
2. JSON 和轻量 XML 交换格式，带结构化校验报告。
3. 基于里程—时间斜线区间的追踪间隔检测、站台占用检测和咽喉资源冲突检测。
4. 实时列车遥测接入、延误传播、陈旧数据告警和事件审计。
5. Hold、Skip、SpeedUp、SlowDown 四类建议动作及安全约束过滤。
6. 面向 Web String Diagram 的无依赖 JSON 渲染流和可导出的 SVG 片段数据。

## 技术路线和交付物

采用纯函数计算和显式状态快照：模型层负责不变量，冲突层负责几何/区间判定，策略层负责候选动作排序，monitor 层负责事件归并，renderer 层只输出展示 DTO。仓库提供可运行 demo、黑盒测试、故障场景回放、README 使用示例和 GitHub Actions CI。

## 规模与后续

目标有效 MoonBit 源码规模约 4,000 行，覆盖可复用库 API、CLI 示例、测试夹具和架构文档。后续可扩展多线折返、站台股道约束、事件总线接入、WebSocket 推送、标准 TMS/ATS 适配器和 mooncakes.io 发布。
