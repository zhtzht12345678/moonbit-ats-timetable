# 8 月黑客松项目申报书

项目名称：MoonBit 列车自动监控（ATS）运行图调度与实时冲突检测器

项目仓库：https://github.com/zhanghantian/moonbit-ats-timetable（推送前按实际 GitHub owner 核对）

项目性质：原创 MoonBit 工程，不是第三方 ATS 的直接移植。核心模型、JSON/XML 交换、静态校验、时空冲突算法、实时监控、策略建议、渲染 DTO、仿真和测试均由本仓库实现。

应用场景：为轨道交通 OCC 提供运行图离线校验、实时状态接入、故障演练和人工调度辅助。项目只输出可解释建议，不直接控制信号、联锁或列车。

本阶段功能：

1. 建模线路、车站、区间、车次、停站、站台和咽喉/进路资源。
2. 支持 JSON 与轻量 XML 交换，并提供完整结构化校验报告。
3. 用里程—时间区间检测 Headway、站台和路线资源冲突。
4. 合并遥测，识别延误增长、位置跳变、未知车次和陈旧数据。
5. 按优先级与运行余量排序 Hold、Skip、SpeedUp、SlowDown 建议。
6. 输出 String Diagram JSON/NDJSON、CSV、SVG，提供 CLI、回放仿真和计划复核。

技术路线：采用纯 MoonBit 的分层库结构；模型层管理不变量，冲突层执行区间相交，策略层过滤安全边界，monitor 层维护快照，renderer 层输出展示数据。仓库包含跨平台 CI、9 个测试用例和合成故障场景。

规模与后续：当前跟踪的有效 MoonBit 源码约 4,291 行，后续扩展标准 TMS/ATS 适配器、事件总线/WebSocket、多线折返和增量资源分片，并发布到 mooncakes.io。

来源与许可证：原创实现，未使用私有、闭源、商业或来源不明代码；演示数据为合成数据。运行时仅依赖 MoonBit 官方核心 JSON 包，项目采用 Apache-2.0。
